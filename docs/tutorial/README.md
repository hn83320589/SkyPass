# SkyPass 教學文件：從需求到可驗證的軟體

本教材以 **SkyPass 過境預報台**為完整案例，示範一個中型專案如何從一份客戶需求，
經過需求分析、系統分析、架構設計、演算法設計、實作與測試，最後交付一個**可驗證**的桌面應用程式。

這不是「怎麼寫衛星程式」的教材。衛星軌道只是題材，真正要學的是：

- 如何把一段模糊的需求，拆成**可以被測試判定**的規格
- 如何用**分層與依賴方向**讓程式容易測試、容易修改
- 如何設計**不會漏掉答案**的搜尋演算法，並證明（或至少強力驗證）它不會漏
- 如何用**獨立的參考解、參考資料與隨機性質測試**，確認自己寫的數值程式是對的
- 如何在多執行緒、取消、進度回報的情況下，保證結果**決定性**且**不會有半套結果**

## 適用對象與先備知識

- 修過程式設計（物件導向）與資料結構；讀得懂 C#（或 Java）
- 修過或正在修系統分析與設計、軟體工程
- 數學：三角函數、向量內積與外積、基本微積分（導數、求根）
- 不需要天文或軌道力學背景：第 2 章會把需要的概念講清楚

## 如何對照程式碼

本教材引用的程式碼都來自同一個 repo，路徑以 repo 根目錄為準，例如 `src/SkyPass.Core/Passes/PassFinder.cs`。
建議邊讀邊開程式碼，並親自執行：

```powershell
dotnet test SkyPass.sln                      # 384 個測試，約 25 秒
dotnet run --project src/SkyPass.App -- --import samples\skypass-samples.tle --now 2026-10-21T10:50:00Z
```
